# Tech logos

Save each brand's official SVG here, using exactly these names:

  flutter.svg · dart.svg · firebase.svg · maps.svg · git.svg · dotnet.svg · sqlite.svg

SVG is used rather than PNG so the marks stay sharp at any badge size and in
any window — the hero scales its badges with the viewport.

Until a file exists, that badge renders as a moulded chip in the brand's own
colours with a placeholder glyph, so a missing logo never breaks the hero.

Take the marks from each project's official brand page and follow their brand
guidelines — do not recolour or restretch them.
